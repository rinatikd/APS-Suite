# APS Suite: Унификация инженерных решений АПС (AutoCAD & Revit)

## Структура решения (монорепозиторий)
- **`APS-Suite/src/APS.Core`** — платформанезависимая библиотека C# (.NET 8 / netstandard2.0) с чистой нормативной и электротехнической математикой (СП 484.1311500.2020, СП РК 2.02-102-2022, падение напряжения в радиальных и кольцевых линиях при обрыве, расчёт ёмкости АКБ, геометрия).
- **`APS-Suite/database/aps_equipment_db.json`** — единая унифицированная база данных оборудования (Рубеж R3, Болид ОРИОН) и нормативных таблиц.
- **`APS_Expert_0_5` (AutoCAD)** — плагин для AutoCAD, переведённый на использование `APS.Core`.
- **`aps-revit` (Revit)** — расширение pyRevit для Autodesk Revit с синхронизированной базой правил и расчётов.
