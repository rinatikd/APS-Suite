# APS Expert 0.2

Интеллектуальный экспертный модуль для AutoCAD, ориентированный на аудит и последующее перепроектирование систем АПС.

## 0.2 — первый анализатор реального проекта

Добавлено:

- чтение RubezhCAD/R-CAD `.rcad` и `RCPD/db_proj_equip.xml`, `RCPD/db_proj_ls.xml`;
- поиск `.rcad` на уровне проекта, если DWG находится в папке `DWG`;
- восстановление оборудования, портов, линий и кабельных сегментов;
- проверка количества адресных устройств на АЛС;
- проверка суммарной длины АЛС;
- выявление портов без явной привязки к линии;
- интеграция этих результатов в `APS_AUDIT`;
- экспорт текущего аудита командой `APS_EXPORT` в `.aps-expert.json`;
- первичный отчёт по реальному проекту `RC_ОПС45`.

## Команды AutoCAD

- `APS_SCAN` — извлечение базовой CAD-модели.
- `APS_AUDIT` — аудит CAD-модели + R-CAD sidecar data.
- `APS_ISSUES` — просмотр результатов.
- `APS_EXPORT` — экспорт JSON-отчёта.
- `APS_MARK` — зарезервировано для графической маркировки.
- `APS_FIX` — зарезервировано для безопасного Preview/Apply/Rollback.

## Важное правило

Проект-эталон используется как источник фактических инженерных решений, но не как доказательство нормативной правильности. Нормативные правила будут подключаться отдельным versioned Rule Pack и ссылаться на конкретные редакции СП РК/СН РК.

## Сборка

Требуется AutoCAD 2026 и его Managed API DLL (`AcCoreMgd.dll`, `AcDbMgd.dll`, `AcMgd.dll`). Путь можно задать через `AUTOCAD_2026_DIR`.

В текущем окружении AutoCAD SDK отсутствует, поэтому бинарный DLL плагина здесь не собирается. Исходный код подготовлен для сборки на машине с установленным AutoCAD 2026.
