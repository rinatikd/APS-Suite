# Reference project: RC_ОПС45

Источник: пользовательский архив `RC_ОПС45.zip`.

## Что обнаружено

Архив содержит:
- `DWG/Улыс Паркинг АПС.dwg`;
- `RCP.rcad`;
- `RCPD/db_proj_equip.xml`;
- `RCPD/db_proj_ls.xml`;
- `RCL/db_equip.xml`;
- `RCL/db_cables.xml`;
- `RCL/db_scheme.xml`;
- настройки RubezhCAD.

`RCP.rcad` подтверждает, что проект создан как проект Rubezh/R-CAD и связан с указанным DWG.

### Проектная модель RubezhCAD

В `RCPD/db_proj_equip.xml` обнаружено 174 проектных элемента.

Основные группы:
- ИП212-64-R3 — 85;
- ИО10220-2 — 22;
- УДП 513-11-R3 — 14;
- ОПОП1-R3 — 11;
- МДУ-1-R3 — 10;
- электромеханический привод — 7;
- РМ-1-R3 — 4;
- ИПР513-11ИКЗ-А-R3 — 3;
- остальные — по 1.

Из проектных XML можно получить:
- тип оборудования;
- артикул;
- УГО;
- позиционное обозначение;
- адресность;
- высоту монтажа;
- привязку к линии;
- тип линии;
- порты оборудования;
- R3-параметры;
- CAD handle;
- идентификатор DWG.

### Линии

Из `db_proj_ls.xml` обнаружены:
- АЛС1.1;
- АЛС1.2;
- C1–C10;
- P1;
- V5 (с пользовательским именем V1).

Связь оборудования с линиями частично задана прямо в `<port ... lsName="...">`.

Это позволяет APS Expert при наличии RubezhCAD-проекта получать точную инженерную модель без попытки угадывать УГО только по графике DWG.

## Архитектурное решение APS Expert 0.2

Добавляется двухуровневый импорт:

1. **Generic DWG extractor**
   - работает с любым AutoCAD-проектом;
   - распознаёт блоки, геометрию, тексты и кабельные линии.

2. **RubezhCAD sidecar importer**
   - если рядом с DWG обнаружен `RCP.rcad`/`RCPD`/`RCL`;
   - использует структурированные данные проекта RubezhCAD;
   - связывает XML-элементы с AutoCAD ObjectId через CAD handle там, где это возможно;
   - повышает достоверность распознавания.

RubezhCAD-данные являются **источником фактической структуры исходного проекта**, но не автоматически считаются нормативно правильными. Нормативная проверка выполняется отдельным Rule Engine.

## Следующий этап

- открыть DWG в AutoCAD;
- сопоставить XML handles с ObjectId;
- извлечь реальные координаты/границы помещений;
- определить типы помещений;
- проверить адресацию;
- построить граф АЛС;
- проверить размещение извещателей;
- затем добавить нормативные правила РК.
