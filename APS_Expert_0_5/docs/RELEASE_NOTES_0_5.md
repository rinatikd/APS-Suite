# 0.5 release notes

0.5 changes the product from a collection of independent checks into an integrated analysis pipeline.

### Added
- ProjectAnalysisContext
- UnifiedModelBuilder
- versioned configurable RulePack
- integrated rule engine
- mapping integrity rule
- ALS integrity rule
- detector-room integrity rule
- optional detector-spacing criterion
- integrated JSON evidence export

### Deliberately not added yet
- automatic DWG edits
- unverified Kazakhstan normative thresholds
- autonomous placement of detectors
- destructive fixes

These are reserved for later stages after the normative Rule Pack and transaction/rollback layer are verified.
