# RubezhCAD ↔ AutoCAD handle mapping

В эталонном проекте поле `handle` имеет формат `HEX#INTERNAL`, например `103512#1125508143`.

Все первые компоненты 174 элементов проекта корректно интерпретируются как hexadecimal AutoCAD handles. APS Expert 0.4 поэтому добавляет экспериментальную команду `APS_MAP_RUBEZH`.

Команда вызывает `Database.GetObjectId(false, new Handle(value), 0)` и проверяет, существует ли соответствующий объект в текущем DWG.

Результат обязан содержать процент совпадения. До подтверждения на реальном DWG эта связь считается технической гипотезой, а не гарантией.

Если совпадение высокое, можно получить для каждого элемента R-CAD:
- точный ObjectId AutoCAD;
- координату BlockReference;
- слой;
- имя блока;
- атрибуты;
- помещение;
- реальные геометрические расстояния.

Это является ключевой точкой перехода от анализа R-CAD XML к анализу фактического DWG.
