# APS Expert 0.2 — интеллектуальный аудит эталонного проекта

## Источник

Использован предоставленный проект `RC_ОПС45`, содержащий DWG и структурированные данные RubezhCAD/R-CAD (`RCPD`, `RCL`).

## Что проверено автоматически

1. Количество оборудования.
2. Привязка оборудования к линиям по данным RCPD.
3. Количество устройств на АЛС.
4. Суммарная длина сегментов АЛС.
5. Порты оборудования без явной привязки к линии.
6. Линии управления и их сегменты.

## Результат

- Всего элементов: **174**.
- АЛС1.1: **130 устройств**, **800.789 м**.
- АЛС1.2: **15 устройств**, **451.151 м**.
- По данным оборудования `R3-Рубеж-2ОП`: предел — 250 адресных устройств на АЛС и 3000 м на АЛС. Обе АЛС проходят эту машинную проверку.
- Найдено **35 портов без явной привязки**. Они имеют статус `WARNING/REVIEW`, а не `ERROR`, поскольку пустая привязка может быть проектным решением.
- Линии управления C1–C10 восстановлены из RCPD; их длины и связи доступны для дальнейших проверок.

## Важное ограничение

Этот аудит **не утверждает нормативную правильность проекта**. Геометрические проверки размещения извещателей, соответствие помещениям, расстояния, зоны защиты, трассировка, кабельные расстояния, СОУЭ и другие проверки требуют связи структурированных данных с объектами AutoCAD и действующим Rule Pack СП РК/СН РК.

## Следующий слой

`Rubezh handle → AutoCAD ObjectId → координаты → помещение → геометрическая проверка → нормативное правило → ProposedChange → Preview → Apply → Re-audit`.
