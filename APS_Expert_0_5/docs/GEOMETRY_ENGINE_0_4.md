# APS Expert 0.4 — Geometry Engine

## Цель

Связать фактические объекты DWG с инженерной моделью АПС: помещения, извещатели, координаты и принадлежность к помещению.

## Что делает 0.4

1. Ищет замкнутые полилинии-кандидаты помещений.
2. Предпочитает слои с признаками `ROOM`, `ПОМ`, `АРХ`, `A-AREA`, `A-ROOM`, `ПОМЕЩ`.
3. Если таких слоёв нет, использует все подходящие замкнутые полилинии и помечает режим как эвристический.
4. Распознаёт блоки извещателей по имени блока/атрибутам.
5. Для каждого извещателя определяет координаты.
6. Определяет помещение методом point-in-polygon.
7. Вычисляет площадь помещения и расстояние от извещателя до ближайшей границы.
8. Формирует пары извещателей внутри одного помещения и их фактические расстояния.
9. Выделяет помещения без найденных автоматических извещателей как `WARNING`, а не как нормативное нарушение.

## Что намеренно НЕ делает

- не утверждает нормативные расстояния без конкретного Rule Pack;
- не утверждает, что помещение обязано иметь АПС только по площади;
- не считает эталонный проект нормативной истиной;
- не изменяет DWG автоматически.

## Следующий этап
