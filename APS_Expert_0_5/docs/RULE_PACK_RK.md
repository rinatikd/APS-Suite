# Rule Pack — Kazakhstan Fire Alarm

## Правила, которые предстоит формализовать

Важно: этот файл фиксирует структуру базы, а не утверждает нормативные значения. Численные требования должны быть занесены только после проверки конкретной действующей редакции СП РК/СН РК и области её применения.

### Группа GEO — размещение
- GEO-001: расстояние извещателя до границы/стены.
- GEO-002: расстояние между извещателями.
- GEO-003: покрытие помещения.
- GEO-004: извещатели в помещениях/зонах, подлежащих защите.
- GEO-005: проверка препятствий и особенностей потолка.

### Группа FAS — архитектура СПС
- FAS-001: корректность подключения устройств к линии.
- FAS-002: совместимость оборудования.
- FAS-003: адресация и уникальность адресов.
- FAS-004: изоляторы/разветвления.
- FAS-005: загрузка линии.
- FAS-006: резервирование.

### Группа CAB — кабель
- CAB-001: тип кабеля.
- CAB-002: длина линии.
- CAB-003: запас кабеля.
- CAB-004: совместная прокладка/разделение трасс.
- CAB-005: соответствие кабеля системе.

### Группа DOC — проектная документация
- DOC-001: устройство на плане есть, в спецификации отсутствует.
- DOC-002: устройство в спецификации отсутствует на плане.
- DOC-003: несоответствие маркировки.
- DOC-004: несоответствие структурной схемы и планов.
- DOC-005: несоответствие кабельного журнала фактической геометрии.
