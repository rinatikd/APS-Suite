# APS Expert 0.4

Первый геометрический анализатор АПС для AutoCAD.

### Новая команда

`APS_GEOMETRY_AUDIT`

Она строит геометрический снимок текущего DWG и формирует результаты:
- помещения;
- извещатели;
- координаты;
- принадлежность извещателей помещениям;
- площадь помещений;
- расстояния до границ;
- попарные расстояния между извещателями;
- помещения без распознанных автоматических извещателей.

Все результаты, где пока нет нормативного порога, имеют информационный/предупреждающий характер.

### Сборка

Требуется AutoCAD 2026 и .NET 8. Перед сборкой задайте `AUTOCAD_2026_DIR`, если AutoCAD установлен не в стандартную папку.
